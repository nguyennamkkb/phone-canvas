phone-canvas — Tổng quan dự án

Design board chứa màn hình điện thoại dưới dạng HTML thật, đo số liệu chính xác từng element để viết SwiftUI.

1. Ý tưởng cốt lõi

Không mô phỏng thiết bị, không viewport cố định, không scroll ẩn. Màn hình cần 992pt thì là hình chữ nhật cao 992pt. <iframe> là nguồn sự thật của layout, SPEC là hợp đồng, panel chỉ là view.

5. Screen regions — shell sở hữu bands

Bạn không vẽ status bar, home indicator, navbar hay tab bar — compose.ts đặt chúng. Bạn khai báo nội dung của band (phone: data-slot="back|title|right" + nút data-tab + band .body/.body-fixed) hoặc cách xếp (iPad/Duo). Gutter 16pt, lưới 4/8pt, mọi element tương tác ≥ 44×44pt. Hiện chỉ band phone là shell-owned; Duo/tablet vẫn author-owned.

Hai tầng kiểm tra, cả hai đều fail npm run gate:

npm run lint:regions    # tĩnh: band shell-owned, slot lạ, anatomy nav/tab, px device, touch floor
npm run audit:regions   # đo thật trên Chrome: rect 44pt, một scroller, overflow, band shell, fold 50/50

7. CSS → SwiftUI (subset)

Flex column/row + gap ↔ VStack/HStack 1:1 · flex-grow ↔ .frame(maxWidth/maxHeight: .infinity) · padding/border-radius/background ↔ .padding/clipShape/.background · box-shadow ↔ .shadow (1 shadow/chuỗi) · line-height − size ↔ .lineSpacing · .icon[data-symbol] ↔ Image(systemName:).

Cố tình không hỗ trợ — extractor báo đỏ Block (out of subset) thay vì giả vờ: display:grid, float, transform, clip-path, filter, mọi layout không phải flexbox.

10. Đã kiểm chứng & việc tiếp theo

Đã kiểm chứng trên instance chạy thật: capture 45–69 element/màn × 37 thuộc tính; chiều cao content được tôn trọng; click trong sandbox → select đúng id; export 9/9 cặp screen×device đúng pixel; icon tint từ currentColor, art giữ màu riêng. Ba bug thật đã bắt được khi chạy: react-flow xóa selection, check WindowProxy làm rơi message iframe, capture chạy trước khi iframe layout xong.

Ngoài phạm vi (chủ ý): sinh code SwiftUI, multi-screen flow dạng edge, persistence (board in-memory).

Tiếp theo: vòng lặp authoring (prompt → screen → export → critique → patch, lint gate từng vòng) · design token dạng data (panel báo #007AFF = --accent) · note từng element (spec thành tài liệu handoff).
