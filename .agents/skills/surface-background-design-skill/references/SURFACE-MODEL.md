# Surface Model Reference

## Vocabulary

**Surface** = the visual plane that groups or separates content.

**Background Treatment** = the visual method applied behind content, such as tonal color, gradient, image, glow, texture, glass, or motif.

**Depth / Elevation** = the perception that a surface sits above or below another surface.

**Decorative Layer** = non-content visual material that contributes to mood, branding, or composition.

**Surface Grammar** = the rules that determine when each surface level and treatment should be used.

## Preferred relationship

```text
Surface System
├── Surface hierarchy
├── Background treatments
├── Depth / elevation
├── Border grammar
├── Radius grammar
└── Decorative layer grammar
```

## Key principle

Do not optimize each component independently. Optimize the relationships between surfaces across the whole screen.
